# Phase 12 — Output Resolution and Core Renderer Integration

## Tasks

### 01 — Review Core renderer contracts and resolve integration prerequisites

Read docs/game-foundation.md and docs/Game/technical-integration.md. Inspect the current Renderer and RenderInput implementations and tests. Decide the minimal game integration seam before changing code.

### 02 — Adapt game layout to configured output resolution

Implement layout scaling and placement for the target output resolutions defined by the Game design. Keep the prototype visually simple and avoid introducing an unnecessary graphics framework.

### 03 — Integrate the game render projection with the Core

Connect the presentation projection to the existing Core Renderer/RenderInput boundary. Preserve authoritative game state outside the renderer and avoid moving YouTube or FFmpeg responsibilities into game modules.

### 04 — Validate frame generation through the local Core pipeline

Use the existing local rendering/demo pipeline to validate frames and integration. Do not require a live YouTube broadcast for ordinary renderer tests.

### 05 — Test and document Core integration

Add tests for render projection and renderer behavior, preserve existing Core tests, and document any new extension points. Any Core behavior change must be separately justified and tested.
