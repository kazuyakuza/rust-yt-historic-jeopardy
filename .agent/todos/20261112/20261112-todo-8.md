# Phase 7 — Scoring System

## Tasks

### 01 — Resolve remaining scoring values

Review docs/Game/scoring-and-leaderboards.md and decisions-to-finalize.md. Decide the outstanding word and phrase completion bonus values and any other unresolved scoring constants before implementing calculations; record the decisions in the scoring specification.

### 02 — Implement letter-reveal scoring

Award points only for newly revealed playable-letter occurrences using the configured vowel and consonant values. Ensure repeated occurrences and simultaneous phrase matches are counted correctly.

### 03 — Implement word and phrase completion bonuses

Award the configured bonuses when an input completes words or phrases. Support multiple completions caused by one input and avoid awarding a completion bonus more than once.

### 04 — Implement hint-based score multipliers

Apply the main-phase hint-count multiplier rules and upward rounding exactly as documented. Do not apply main-phase hint multipliers to additional-phrase scoring.

### 05 — Expose transient scoring breakdowns

Represent the per-input score components in memory so tests and diagnostics can inspect how points were calculated. Do not add permanent persistence for these breakdowns.

### 06 — Test scoring and document finalized values

Cover letter counts, hidden-versus-visible letters, word and phrase bonuses, multiple completions, multiplier boundaries, and rounding. Update the scoring specification with the final values and examples.
