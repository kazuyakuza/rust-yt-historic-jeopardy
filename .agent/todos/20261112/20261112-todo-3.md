# Phase 2 — Persistence and Phrase Database Foundation

## Tasks

### 01 — Resolve database design prerequisites

Review docs/Game/phrase-data.md and technical-integration.md. Decide the SQLite library, migration approach, schema ownership, and database location/configuration needed for this phase before implementation.

### 02 — Design and create the SQLite schema

Implement the foundational schema for phrases, original and normalized text, source attribution, context, three hints, individual difficulty metadata, and other prepared phrase attributes described by the Game specifications.

### 03 — Implement database initialization and migrations

Provide reliable first-run database creation and versioned schema migration behavior. Ensure repeated initialization is safe and failures are surfaced clearly.

### 04 — Implement phrase persistence access layer

Provide typed operations for inserting, retrieving, updating, and validating prepared phrase records. Keep SQL and persistence concerns out of the game domain.

### 05 — Test persistence and document the database contract

Cover schema constraints, migrations, round-trip behavior, invalid records, and failure paths. Document schema ownership, initialization, migration, and local database handling.
