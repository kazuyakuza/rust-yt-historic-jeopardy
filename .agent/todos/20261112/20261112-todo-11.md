# Phase 10 — Game Information and Instructions UI

## Tasks

### 01 — Resolve information placement and presentation prerequisites

Review docs/Game/game-design.md, gameplay-rules.md, and scoring-and-leaderboards.md. Decide final placement and compact visual treatment for phrase difficulty, game difficulty, hints, instructions, and state indicators before implementation.

### 02 — Display hints and difficulty indicators

Show the three-hint progression for the main phrase and the selected hint for each additional phrase. Display individual phrase difficulty and overall game difficulty in the agreed locations.

### 03 — Display game state and viewer instructions

Present the current phase/status and concise, readable instructions for valid chat inputs, including the accepted A–Z character rules and slash prefix.

### 04 — Prepare reusable video-description rules

Provide the complete viewer-facing instructions in a form that can also be copied into the YouTube video description. Keep the on-screen version appropriately concise.

### 05 — Test information visibility and document the UI contract

Validate each phase and hint state using render fixtures, including long hints and variable phrase counts. Document the presentation model and any layout limits.
