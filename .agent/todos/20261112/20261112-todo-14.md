# Phase 13 — Chat Input Processing and Game Updates

## Tasks

### 01 — Resolve chat adapter and sequencing prerequisites

Review docs/Game/gameplay-rules.md, technical-integration.md, and docs/game-foundation.md. Confirm the message-to-game adapter boundary and FIFO sequencing behavior before implementation.

### 02 — Adapt Core chat messages to game input

Convert incoming application-level chat messages into the game's input request while retaining stable YouTube user identity and original message metadata needed by the adapter.

### 03 — Apply inputs to active game and update presentation

Route accepted inputs to the active game engine, then publish score and render-projection changes. Ensure inputs cannot mutate a game when no game is active.

### 04 — Preserve activity versus participation distinction

Keep receipt of any chat message distinct from valid scoring participation so the later audience lifecycle can use all chat messages as activity.

### 05 — Test message integration and document the adapter

Test FIFO ordering, valid and invalid inputs, player identity, multiple messages, and no-active-game behavior with synthetic messages. Document the adapter contract.
