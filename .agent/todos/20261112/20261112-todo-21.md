# Phase 20 — Historical Metrics and Game Admission

## Tasks

### 01 — Resolve metrics definitions and fallback estimate

Review Technical Integration, Stream Lifecycle, and Decisions to Finalize. Confirm the exact metrics schema, sample sufficiency rule, and configurable fallback duration estimate before implementation.

### 02 — Implement historical game and stream metrics

Persist the agreed aggregate counts and durations, including player counts, valid game input counts, game counts, average game duration, and average games per stream as specified.

### 03 — Calculate duration estimates from available history

Calculate the average duration from eligible historical games and use the configured fallback estimate when the historical sample is insufficient.

### 04 — Integrate estimated duration with game admission

Expose a deterministic admission decision based on the expected game duration and remaining stream time. Keep the decision independent of the renderer.

### 05 — Test metrics and document calculation semantics

Test empty history, insufficient samples, changing averages, stream aggregation, and admission boundaries. Document metric definitions, retention, and estimate behavior.
