# Phase 9 — Additional Phrases Vertical Presentation

## Tasks

### 01 — Define vertical phrase layout constraints

Review docs/Game/game-design.md, gameplay-rules.md, and technical-integration.md. Establish layout constraints for the expected additional phrase count, varying phrase lengths, and crossing positions.

### 02 — Implement vertical phrase rendering

Render all additional phrases vertically and simultaneously, with each phrase crossing the main phrase at its designated shared letter. Additional phrases must not visually imply intersections with one another.

### 03 — Handle reveal-state and layout changes

Ensure letter revelation, word completion, and phrase completion are reflected without losing the alignment of crossing letters or causing avoidable layout instability.

### 04 — Validate representative layouts and document presentation

Use fixture-driven render tests or visual snapshots where supported for minimum/maximum phrase counts and varied phrase lengths. Document the layout decisions and known constraints.
