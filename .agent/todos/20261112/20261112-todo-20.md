# Phase 19 — Phrase Availability Reset on New Stream

## Tasks

### 01 — Resolve phrase reservation and reuse semantics

Review Phrase Data, Stream Lifecycle, and Technical Integration. Confirm the timestamp model and transactional reservation behavior before implementation.

### 02 — Implement per-stream phrase selection timestamps

Record the time each phrase is selected for a game and exclude it from further selection until its configured reuse interval expires.

### 03 — Implement per-phrase availability expiration

Make phrases available again independently when their own reuse interval elapses, even while the same stream continues.

### 04 — Reset availability at new stream initialization

Ensure all phrases are available at the beginning of every new stream, regardless of the previous stream's start or end time. Keep historical selection information only if required for metrics/audit.

### 05 — Test availability lifecycle and document semantics

Test staggered selection times, reuse boundaries, concurrent reservation safety, and new-stream reset. Document the lifecycle and database behavior.
