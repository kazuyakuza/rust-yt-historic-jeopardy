# Phase 15 — Stream Leaderboard

## Tasks

### 01 — Resolve stream leaderboard persistence and ranking prerequisites

Review docs/Game/scoring-and-leaderboards.md, stream-lifecycle.md, and technical-integration.md. Confirm the in-memory/persistent boundary and the complete tie-ordering behavior before implementation.

### 02 — Implement stream victory aggregation

Accumulate one victory point for each co-winner of each completed game, preserving player identity throughout the stream.

### 03 — Implement stream leaderboard ranking and result groups

Implement the documented shared-position rules for the top three and alphabetical ordering for remaining displayed positions. Preserve all players tied in a top-three group even if the resulting display exceeds ten entries.

### 04 — Expose standings for intermission and final presentation

Provide a stream leaderboard projection that can be consumed by intermission and final-results presentation without coupling ranking logic to the renderer.

### 05 — Test and document stream leaderboard behavior

Test repeated victories, co-winners, ties at each top-three boundary, alphabetical ordering, and expanded result groups. Document the ranking contract.
