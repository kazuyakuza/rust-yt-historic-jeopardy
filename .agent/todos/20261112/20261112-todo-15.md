# Phase 14 — Demo Input Source

## Tasks

### 01 — Review existing Core demo source and resolve demo integration

Read docs/game-foundation.md and the existing demo documentation/source. Choose the minimal extension that supplies synthetic game messages without contacting YouTube or OAuth.

### 02 — Implement deterministic synthetic players and messages

Create a local demo input source capable of producing messages from multiple stable synthetic players and a controlled sequence of game inputs.

### 03 — Support complete offline game demonstrations

Allow a full game flow to be exercised locally, including phase transitions, hints, scoring, leaderboards, and rendering.

### 04 — Test and document demo execution

Test deterministic replay and ensure the demo does not invoke YouTube/OAuth. Document local commands, configuration, and how to use the demo for manual visual validation.
