# Phase 6 — Hints and Timers

## Tasks

### 01 — Resolve hint and timer configuration prerequisites

Review docs/Game/gameplay-rules.md, technical-integration.md, and decisions-to-finalize.md. Settle the required intervals, timer ownership, and display-to-logic delay behavior before implementation.

### 02 — Implement main-phrase hint progression

Support exactly three prepared hints for the main phrase and reveal them sequentially according to the configured countdown.

### 03 — Implement additional-phrase hint selection

When the additional-phrases phase begins, immediately display one randomly selected hint from each phrase. Do not introduce a hint countdown, scoring modifier, or delayed reveal in this phase.

### 04 — Implement countdown reset and transition behavior

Reset the main hint countdown only for valid inputs that award points, following the documented rules. Ensure invalid and non-scoring inputs do not reset it; handle exhausted hints without unnecessary timer work.

### 05 — Implement viewer-display delay and deterministic timer seams

Implement the configured delay between publishing a viewer-visible countdown/start message and activating the corresponding internal timer. Use an injected clock or equivalent deterministic seam.

### 06 — Test timers and document timing semantics

Test timer boundaries, hint progression, valid-input resets, phase transitions, and display-to-logic delay without real sleeping. Document configuration and the known approximate YouTube latency caveat.
