# Phase 1 — Game Domain Foundation

## Tasks

### 01 — Define domain contracts and unresolved prerequisites

Review docs/Game/game-design.md, gameplay-rules.md, phrase-data.md, scoring-and-leaderboards.md, and technical-integration.md. Resolve only domain-model decisions needed for this phase before coding; record decisions in the relevant Game specification.

### 02 — Implement core game domain types

Introduce the core phrase, word, playable-character, hint, player, game, phase, and input concepts. Keep these types independent of persistence, rendering, YouTube transport, and stream lifecycle.

### 03 — Implement canonical phrase and input primitives

Implement the normalized-text representation and accepted-input validation primitives according to docs/Game/phrase-data.md and gameplay-rules.md. Preserve the distinction between prepared phrase text and viewer-supplied input; do not silently broaden accepted input.

### 04 — Separate authoritative state from presentation projection

Define the boundary between mutable game state and read-only data required by a renderer. Avoid renderer-specific fields in authoritative domain types.

### 05 — Add deterministic domain tests and documentation

Test domain invariants, normalization and validation boundaries, and invalid states. Document the domain contracts and update relevant Game specifications without duplicating their full rules.

## Delivery Expectations

- Include phase-appropriate automated tests and any required manual validation in the implementation tasks; do not defer testing to a later phase.
- Update the relevant documentation as part of this phase. Prefer references to the source-of-truth specifications over copying their content into this TODO.
- Resolve any still-open decision needed by a task before implementing that behavior, and record the decision in the appropriate specification.
- Preserve existing Core contracts unless a separately justified and tested change is explicitly required.
- Keep the work locally testable wherever practical. Do not introduce remote deployment or VPS setup work.
