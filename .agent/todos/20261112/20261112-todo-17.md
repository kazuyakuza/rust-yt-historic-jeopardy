# Phase 16 — Chat Activity Detection

## Tasks

### 01 — Resolve activity signal integration prerequisites

Review docs/Game/stream-lifecycle.md and technical-integration.md. Confirm which Core message receipt event is authoritative and where activity timestamps are maintained.

### 02 — Implement chat-first activity tracking

Record activity whenever a chat message is received, whether or not it is a game input and whether or not it is valid for scoring.

### 03 — Integrate activity with lifecycle cancellation

Expose activity changes to the stream lifecycle so pending no-activity waits and viewer fallback checks can be cancelled or reset when a message arrives.

### 04 — Test activity and participation separation

Test non-game messages, malformed inputs, valid scoring inputs, activity during waits, and transitions between active/inactive periods. Document the activity event contract.
