# Phase 5 — Main and Additional Phrase Gameplay

## Tasks

### 01 — Resolve gameplay selection and crossing prerequisites

Review docs/Game/gameplay-rules.md, phrase-data.md, and decisions-to-finalize.md. Resolve any remaining phrase-selection, crossing-letter, or difficulty aggregation decisions required for this phase before implementation.

### 02 — Implement game phrase selection

Select the main phrase and the configured random number of additional phrases from the prepared dataset. Keep random selection deterministic under test and independent of difficulty labels.

### 03 — Implement additional-phrase intersections and game difficulty

Connect each additional phrase to the main phrase using exactly one shared letter, without connecting additional phrases to one another. Calculate the informational game difficulty after selection.

### 04 — Implement main and additional gameplay phase transitions

Implement the main phrase phase and transition to the simultaneous additional-phrases phase when the main phrase is completed. Ensure all additional phrases become active together.

### 05 — Implement letter revelation and word/phrase evaluation

Apply valid letter, word, and phrase guesses across the active phrase set. Reveal all occurrences of a guessed normalized letter and award no duplicate reveal for already-visible characters. Handle multiple simultaneous matches and completions.

### 06 — Test gameplay engine and document behavior

Use deterministic phrase fixtures and seeded selection to test phase transitions, crossings, repeated letters, multiple active phrases, and combined inputs. Update gameplay documentation for any decisions finalized during implementation.
